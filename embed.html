🧩 Widgets gratis para tu web

¿Tienes un blog, una web de fitness o de nutrición? Incrusta esta calculadora de IMC directamente en tu página, gratis y sin registro. Solo pega este código donde quieras que aparezca:

<div data-hr-widget="imc"></div>
<script src="https://dariodorge.github.io/prueba_claude/embed/imc.js" async></script>

Condiciones

  • Gratis para cualquier web, personal o comercial.
  • Se pide mantener el pequeño enlace de crédito ("Widget de Herramientas Rápidas") que lleva el propio widget — es la única condición.
  • El widget corre en el navegador del visitante; no recogemos datos de quien lo usa.

Irán apareciendo más widgets (propina, porcentajes...) — si necesitas uno en concreto, abre un issue en GitHub.
