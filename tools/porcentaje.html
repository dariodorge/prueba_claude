¿Qué porcentaje es X de Y? Útil para descuentos, subidas de precio o análisis rápidos.

Otros usos comunes

Para calcular un descuento: introduce el porcentaje de rebaja y el precio original: el resultado te dice cuánto se resta. Para calcular una subida de precio, funciona igual pero sumando el resultado al valor original.
